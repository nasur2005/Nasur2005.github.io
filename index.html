How it's built

One practice session, start to finish

  1. The browser records audio with the MediaRecorder API and sends it with the topic and duration as a form upload.
  2. FastAPI validates the upload (size, length) and sends the audio to Whisper, prompted to keep dialect words as spoken.
  3. The transcript goes to an LLM with a coaching prompt that requires a fixed JSON shape; the server parses and clamps the result.
  4. Python computes pace, filler rate, vocabulary diversity and dialect rate after normalizing the Arabic text.
  5. Everything is saved to one SQLite row, and the browser renders the feedback and charts progress.

API

  • GET /api/topic a random speaking prompt
  • POST /api/sessions audio in, transcript, metrics and feedback out
  • GET /api/sessions session history
  • GET /api/progress per-session metrics with rolling averages
